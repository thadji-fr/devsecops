# Note de transition — Nouveau périmètre de l'étude de cas 02

La première version de ce document assimilait trop souvent Salt à la diffusion de correctifs de sécurité.

**Lire désormais : [Administrer plusieurs postes Windows avec Salt, maintenir les logiciels avec Chocolatey](02-salt-chocolatey-administration.md).**

- **Chocolatey** : installer, mettre à niveau et désinstaller des logiciels sur un poste Windows, notamment depuis une source interne.
- **Salt** : piloter plusieurs machines à distance, exécuter des commandes CMD/PowerShell, collecter les résultats, inspecter les services et appliquer des états.
- **Mises à jour à distance** : Salt peut déclencher une commande Chocolatey sur les machines ciblées, mais ce n'est qu'un usage parmi d'autres.
- **CVE** : contexte possible d'une mise à jour, pas la définition de Salt.

Ce fichier reste accessible afin de ne pas rompre les anciens liens.
